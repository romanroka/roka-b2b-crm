# Как открыть приложение как обычный сайт — без терминала

Смысл: приложение будет лежать на бесплатном сервисе Streamlit Cloud, и у тебя
будет постоянная ссылка вида `https://roka-b2b-crm.streamlit.app`. Открываешь
её в браузере (можно добавить на главный экран телефона как иконку) — и сразу
интерфейс, как обычный сайт. Ничего устанавливать на компьютер не нужно.

Всё, что ниже, делается мышкой в браузере. Терминал не понадобится ни разу.

Уйдёт минут 20–30, в основном на шаги 1–3 (это разовая настройка Google, дальше
всё быстро).

---

## Шаг 1. Создай Google-таблицу

1. Открой [sheets.google.com](https://sheets.google.com).
2. Создай новую пустую таблицу.
3. Назови её ровно **ROKA B2B CRM** (или как хочешь — тогда потом впишешь это же имя в секреты на шаге 6).
4. Больше в таблице ничего не трогай — приложение само создаст нужный лист и колонки при первом запуске.

## Шаг 2. Создай "служебный аккаунт" Google (чтобы приложение могло писать в таблицу)

Это не твой личный аккаунт, а технический — только для доступа к таблице.

1. Открой [console.cloud.google.com](https://console.cloud.google.com/).
2. Наверху создай новый проект (кнопка выбора проекта → New Project), назови как угодно, например `roka-crm`.
3. В левом меню: **APIs & Services → Library**. Найди и открой **Google Sheets API** → нажми **Enable**. Вернись и так же включи **Google Drive API**.
4. В левом меню: **APIs & Services → Credentials**.
5. Нажми **+ Create Credentials → Service Account**. Дай имя, например `roka-crm-bot`, жми Done.
6. Открой созданный аккаунт (клик по нему в списке) → вкладка **Keys** → **Add Key → Create new key** → выбери **JSON** → Create.
7. Автоматически скачается файл (типа `roka-crm-123456.json`). Он тебе понадобится на шаге 6 — не удаляй, но и никуда не заливай (это секретный ключ).

## Шаг 3. Дай доступ к таблице этому служебному аккаунту

1. Открой скачанный на шаге 2.7 файл в любом текстовом редакторе (например, TextEdit на Mac — просто открой файл двойным кликом, если спросит "чем открыть" — выбери "Текстовый редактор" или Блокнот, не Excel).
2. Найди строку `"client_email"` — это будет что-то вроде `roka-crm-bot@roka-crm-123456.iam.gserviceaccount.com`. Скопируй это значение.
3. Вернись в свою Google-таблицу (шаг 1) → кнопка **Поделиться** (Share) в правом верхнем углу → вставь скопированный email → выбери права **Редактор** → Отправить.

Без этого шага таблицу приложение не увидит.

## Шаг 4. Получи ключ Claude (для генерации писем)

1. Открой [console.anthropic.com](https://console.anthropic.com/).
2. Зарегистрируйся/войди, привяжи способ оплаты (генерация писем стоит копейки за письмо, но без оплаты API не работает).
3. В разделе API Keys создай новый ключ, скопируй и сохрани его куда-нибудь (типа заметки) — он понадобится на шаге 6, и повторно посмотреть его будет нельзя.

## Шаг 5. Залей код на GitHub (через браузер, без git)

1. Открой [github.com](https://github.com), зарегистрируйся бесплатно, если нет аккаунта.
2. Нажми **+** в правом верхнем углу → **New repository**.
3. Назови репозиторий, например `roka-b2b-crm`. Выбери **Private**. Нажми **Create repository**.
4. На странице пустого репозитория нажми ссылку **uploading an existing file**.
5. Перетащи мышкой в окно браузера ВСЕ файлы из папки `roka_b2b_mvp`, которую я прислал, **КРОМЕ**: `.env`, `.env.example`, `credentials.json` (их там и не должно быть, если ты их не создавал — просто убедись, что не тащишь ничего похожего на секретный ключ).
6. Внизу нажми **Commit changes**.

## Шаг 6. Запусти приложение на Streamlit Cloud

1. Открой [share.streamlit.io](https://share.streamlit.io/).
2. Войди через свой аккаунт GitHub (кнопка Continue with GitHub), разреши доступ.
3. Нажми **Create app** (или **New app**).
4. Выбери свой репозиторий `roka-b2b-crm`, ветку `main`, файл `app.py`.
5. Перед тем как жать Deploy — открой **Advanced settings**. Там будет поле **Secrets**.
6. Открой в проекте файл `secrets_template.toml` (я его туда положил специально для этого шага), скопируй его содержимое целиком, вставь в поле Secrets.
7. Замени в нём все `ВСТАВЬ_СЮДА` на реальные значения:
   - Поля `project_id`, `private_key_id`, `private_key`, `client_email`, `client_id`, `client_x509_cert_url` — бери из JSON-файла со Шага 2.7 (просто открыт в текстовом редакторе, копируешь значение в значение).
   - `ANTHROPIC_API_KEY` — ключ со Шага 4.
   - `GOOGLE_SHEET_NAME` — точное имя твоей таблицы со Шага 1.
   - `SENDER_NAME`, `SENDER_ROLE`, `SENDER_EMAIL` — как подписывать письма.
8. Нажми **Save**, потом **Deploy**.

Подожди 1–3 минуты, пока соберётся — и всё, готова постоянная ссылка на приложение.
Сохрани её в закладки — дальше просто открываешь её как обычный сайт.

---

## Если что-то в будущем захочешь поменять в коде

Заходишь на github.com в свой репозиторий → открываешь нужный файл → нажимаешь
значок карандаша (Edit) → правишь прямо в браузере → Commit changes.
Streamlit Cloud сам подхватит изменения и переразвернёт приложение за минуту-две.
Никакого терминала и тут не нужно.

## Если что-то не запустилось

Открой ссылку на приложение — Streamlit Cloud обычно сразу показывает текст
ошибки на странице (или в логах — кнопка "Manage app" внизу справа). Почти
всегда причина одна из двух:
- в Secrets опечатка или не заменили какой-то `ВСТАВЬ_СЮДА`;
- таблицу забыли расшарить на `client_email` из Шага 3.
