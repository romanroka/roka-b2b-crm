# Подключение Gmail (опционально)

Эта настройка нужна ТОЛЬКО если хочешь, чтобы приложение само импортировало
переписку из твоего Gmail и определяло, на какой стадии находится каждый
клиент. Без неё всё остальное приложение работает как обычно.

Важно понимать заранее:
- Это ОТДЕЛЬНАЯ настройка от сервис-аккаунта, который уже используется для
  Google-таблицы (тот трогать не нужно).
- Приложение получает доступ ТОЛЬКО НА ЧТЕНИЕ твоей почты — отправлять,
  удалять или менять письма оно не может физически (в коде запрошено только
  право на чтение).
- Настоящей фоновой синхронизации 24/7 нет, потому что бесплатный хостинг
  Streamlit не держит постоянно работающий процесс — импорт письма
  запускается: (а) вручную первый раз (может занять пару минут — за раз
  подтягивается до 12 месяцев переписки), и (б) дальше сам, при каждом
  открытии приложения (но не чаще, чем раз в 15 минут, чтобы не дёргать API
  зря).
- Пока твоё приложение в Google в статусе "Тестирование" (обычный случай для
  личного использования) — доступ будет нужно обновлять раз в 7 дней одной
  кнопкой ("Se connecter avec Google"). Это ограничение самого Google для
  неопубликованных приложений, не баг.

## Шаг 1. Включи Gmail API

1. Открой [console.cloud.google.com](https://console.cloud.google.com/) →
   выбери тот же проект, что уже используешь для Google-таблицы.
2. В поиске сверху введи "Gmail API" → открой → нажми **Activer** (Enable).

## Шаг 2. Настрой экран согласия (OAuth consent screen)

1. Слева в меню: **API et services** → **Écran de consentement OAuth**.
2. Тип пользователя: **Externe** (External) → Créer.
3. Заполни обязательные поля: название приложения (например "ROKA CRM"),
   свой email в двух местах (email поддержки и email разработчика).
4. На шаге "Scopes" ничего добавлять не обязательно — жми Enregistrer et
   continuer.
5. На шаге "Utilisateurs de test" (Test users) — добавь СВОЙ собственный
   Gmail-адрес (тот, откуда будешь импортировать почту). Это обязательно,
   иначе Google не даст авторизоваться, пока приложение не опубликовано.
6. Сохрани всё остальное по умолчанию.

## Шаг 3. Создай OAuth-клиент

1. Слева: **API et services** → **Identifiants** (Credentials).
2. **Créer des identifiants** → **ID client OAuth**.
3. Type d'application: **Application Web**.
4. Название — любое, например "ROKA CRM Web".
5. В поле **URI de redirection autorisés** укажи ТОЧНЫЙ адрес твоего
   задеплоенного приложения на Streamlit Cloud, с завершающим "/", например:
   `https://roka-b2b-crm.streamlit.app/`
   (это тот же адрес, что ты открываешь в браузере, чтобы попасть в
   приложение — просто скопируй его из адресной строки и добавь "/" в конце,
   если его нет).
6. Créer → появится окно с **ID client** и **Code secret du client** —
   скопируй оба, они понадобятся дальше.

## Шаг 4. Добавь данные в Secrets

На Streamlit Cloud: **Manage app** → **Settings** → **Secrets** → добавь (или
обнови, если уже используешь `secrets_template.toml`) три строки:

```toml
GMAIL_CLIENT_ID = "вставь ID client сюда"
GMAIL_CLIENT_SECRET = "вставь Code secret сюда"
GMAIL_REDIRECT_URI = "https://roka-b2b-crm.streamlit.app/"
```

Важно: эти три строки, как и остальные обычные настройки, должны идти ДО
блока `[gcp_service_account]` в Secrets (см. комментарий в самом начале
файла `secrets_template.toml`).

Сохрани — приложение перезапустится само.

## Шаг 5. Подключи Gmail в самом приложении

1. Открой приложение → вкладка **📧 Gmail**.
2. Нажми **🔐 Se connecter avec Google** → выбери свой Gmail-аккаунт →
   разреши доступ на чтение (Google может показать предупреждение
   "приложение не проверено Google" — это нормально для личного
   использования в статусе "Тестирование": нажми "Advanced" →
   "Go to ROKA CRM (unsafe)", это твоё собственное приложение).
3. Тебя вернёт обратно в приложение с сообщением "Gmail подключён".
4. Нажми **📥 Premier import (12 mois)** — подожди (может занять пару минут).
5. Готово — во вкладке появятся все найденные разговоры со стадией и
   рекомендованным следующим действием от ИИ, а подходящие клиенты сами
   свяжутся (или создадутся) в основной базе.

## Если через 7 дней доступ "отвалился"

Это нормально для неопубликованного (тестового) OAuth-приложения — Google
сам аннулирует токен через 7 дней. Просто снова зайди во вкладку **📧 Gmail**
и нажми **🔐 Se connecter avec Google** — все данные, которые уже
импортированы, никуда не денутся, подключится только заново сама связь.
